Нягтаа: Факт гаригийн аян (2.5D тоглоом)

Mac дээр турших: Finder-ээс Play-Game.command файлыг давхар дарна.
Тоглоом хөтөч дээр нээгдэнэ. Terminal цонхыг нээлттэй байлгаж, дуусмагц
Ctrl + C дарж серверийг зогсооно. Python 3 хэрэгтэй.

Ажиллуулах: энэ хавтсыг ямар нэг вэб сервер дээр байршуулна (жишээ нь: python3 -m http.server 8000, дараа нь http://localhost:8000).
Файлыг шууд давхар товшиж (file://) нээвэл хөтөч зураг, дууг ачаалахгүй.
Phaser 3.80.1-ийг cdnjs-ээс ачаалдаг тул интернет хэрэгтэй.

Хэл: тоглоом нээгдэх бүрд Монгол / English сонгох дэлгэц гарна.
Хэлээ дарсны дараа тоглоом сонгосон хэлээр ачаалж, үндсэн цэс нээгдэнэ.
Өмнөх сонголтыг санах боловч хэл сонгох дэлгэцийг алгасахгүй.
Тоглож байхдаа дэлгэцийн дээд хэсгийн MN / EN товчоор хэлээ сольж болно.
Цэс, 42 ярианы текст, сэжүүр, тэмдэглэл, асуулт, тайлбар, зураг дээр кодоор
зурсан бичвэрүүд хэлээ шууд солино. Оноо, хугацаа, цуглуулсан сэжүүрүүд
хэвээр үлдэнэ. Анхны хэл MN; сонголтыг энэ хөтөч дээр хадгална.
Дөрвөн видео EN үед англи хадмалтай. MN үед бичлэгийн эх монгол хадмал
харагдана. Видео тоглож байхад хэл солиход тухайн мөчөөс үргэлжилнэ.
Эх MP4 файлыг өөрчлөхгүйгээр англи хадмалын битүү дэвсгэр нь монгол
хадмалыг халхална. Дуу оруулга, дүрсэн дэх зурагт хуудас, логоны бичвэр
нь эх бичлэгээрээ үлдэнэ.

Англи UI орчуулга: js/i18n.js. Ярианы MN/EN эх: js/data.js доторх L.
Видеоны англи хадмал, хугацаа: js/video-captions.js.
Бүх автомат шалгалт: node --test tests/*.test.cjs
Зураг, дуу, видео болон хуудасны шаардлагатай файлууд байгаа эсэх,
Git-д бүртгэлтэй эсэх: node --test tests/assets.test.cjs
Шинэ файл нэмэхдээ git add хийсний дараа шалгалтыг ажиллуулна.
GitHub-д push хийх болон pull request нээхэд эдгээр шалгалт автоматаар ажиллана.

Background: sky/far/near давхаргуудыг эх зургийн хэмжээнээс үл хамааран
2400×1080 орчинд харуулна. Дүрүүд, сэжүүрүүдийн координат үүнтэй таарна.
Төмөрийн ярианы тусгай төрх байхгүй үед gamer_main.webp зургийг ашиглана.
